# Adobe Media Encoder capability audit for MediaCraft

**Scope:** Adobe's Media Encoder Desktop Help navigation, reviewed 2026-11-01. Each topic in the current help index is accounted for below; detailed subtopics from the overview and export-settings references are included. This is exhaustive against the linked help index, not every codec option, plug-in, undocumented behavior, or release note. Re-audit when Adobe changes the index. Adobe's UI inventory is not the same as its automation/API surface.

**Status key:** `Core` informs MediaCraft's product scope; `Adjacent` is a supporting or integration concern; `External` is Adobe-specific infrastructure or service. This document records reference capabilities and requirements, not MediaCraft implementation claims.

## Enumerated workflow capabilities

The overview and encode/export guides establish these related behaviors, which are tracked as separate requirements even where the navigation groups them under one topic:

| Capability | Source | MediaCraft requirement |
|---|---|---|
| Add files, sequences, and compositions; drag/drop or browse | [Overview](https://helpx.adobe.com/media-encoder/desktop/encoding-quick-start-and-basics/overview-media-encoder-user-interface.html) | Accept catalog assets and explicit external/project sources |
| Send jobs from other Adobe apps and continue editing while encoding | [Overview](https://helpx.adobe.com/media-encoder/desktop/encoding-quick-start-and-basics/overview-media-encoder-user-interface.html) | IPC/API hand-off from FilmCraft/EffectCraft with idempotent job IDs and receipts |
| Defer start, start immediately, or start after an interval | [Overview](https://helpx.adobe.com/media-encoder/desktop/encoding-quick-start-and-basics/overview-media-encoder-user-interface.html) | Explicit queue start policy; no hidden auto-start |
| Remove, duplicate, skip, reset status, and reorder queued items; outputs currently encoding cannot be edited | [Encode/export](https://helpx.adobe.com/media-encoder/desktop/encoding-and-exporting/encode-export-video-audio.html) | Persisted state transitions, retry/skip semantics, and immutable active work units |
| Watch folders automatically submit new files with selected presets; multiple folder entries can create multiple outputs for each source | [Encode/export](https://helpx.adobe.com/media-encoder/desktop/encoding-and-exporting/encode-export-video-audio.html) | Stable-file detection, deduplication, rule versioning, bounded retries, and one source to many derivative jobs |
| Browse drives/favorites, preview media, filter/search, and add to queue | [Overview](https://helpx.adobe.com/media-encoder/desktop/encoding-quick-start-and-basics/overview-media-encoder-user-interface.html) | Bridge-like catalog plus direct process action |
| Encode multiple outputs from one source simultaneously while processing source items in queue order; show progress/status | [Overview](https://helpx.adobe.com/media-encoder/desktop/encoding-quick-start-and-basics/overview-media-encoder-user-interface.html), [Encode/export](https://helpx.adobe.com/media-encoder/desktop/encoding-and-exporting/encode-export-video-audio.html) | Per-output progress and resource-aware concurrency; preserve ordering and source/output relationship |
| Set output name/location and resolve existing-file conflicts | [Encode/export](https://helpx.adobe.com/media-encoder/desktop/encoding-and-exporting/encode-export-video-audio.html) | Preflight collisions, explicit overwrite policy, atomic output strategy |
| Create custom preset/group and import/export reusable settings | [Custom presets](https://helpx.adobe.com/media-encoder/desktop/encoding-and-exporting/custom-encoding-presets.html) | Versioned recipes; record recipe hash/version with output provenance |
| Inspect source/output preview and trim export range | [Export settings](https://helpx.adobe.com/media-encoder/desktop/encoding-and-exporting/export-settings-reference.html) | Show expected transformation and exact trim/timebase semantics before execution |
| Configure effects (including Lumetri, tone mapping/HDR-to-SDR, overlays), captions, metadata, publish, video, and audio settings | [Export settings](https://helpx.adobe.com/media-encoder/desktop/encoding-and-exporting/export-settings-reference.html) | Typed settings with schema validation; unsupported settings fail clearly |

## Audit boundary and source ledger

The source-of-scope is the current [Adobe Media Encoder Desktop Help index](https://helpx.adobe.com/media-encoder/desktop.html). The audit accounts for every topic in its Introduction, Encoding quick start and basics, and Encoding and exporting navigation. The detailed Export Settings reference and overview were decomposed into explicit workflow capability rows. Troubleshooting/release pages are change-monitoring sources, not feature claims. The older reference PDF is supplemental only. This audit does not claim to inventory every plug-in, codec implementation, API member, hardware-specific restriction, or unpublished behavior.
