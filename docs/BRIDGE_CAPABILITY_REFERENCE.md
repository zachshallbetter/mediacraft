# Adobe Bridge capability audit for MediaCraft

**Scope:** Adobe's Bridge Desktop Help navigation, reviewed 2026-11-01. Each index topic is accounted for below. This is exhaustive against the linked desktop-help index, not every feature hidden in every dialog, plugin, or release note. Adobe can add pages; re-audit when the index changes. Bridge's automation/API surface is not assessed here.

**Status key:** `Relevant` maps to MediaCraft product scope; `Adjacent` is an optional ecosystem/service capability; `Out of scope` is Adobe cloud/app-specific functionality. This table describes Bridge capabilities, not current MediaCraft implementation.

## MediaCraft coverage mapping

The reference coverage maps to the product direction in [FEATURES.md](FEATURES.md), [DEFINITION.md](DEFINITION.md), and [MEDIACRAFT_CAPABILITY_AUDIT.md](MEDIACRAFT_CAPABILITY_AUDIT.md). Treat rows marked Relevant as requirements/reference behavior, not proof of implementation. Product priority should start with browse, preview, metadata, search/filter, labels/ratings, collections, stacks, safe rename, contact sheets, and app hand-off. Cloud publishing and Adobe-specific panels are optional integrations.

## Audit boundary and source ledger

The source-of-scope is the linked [Adobe Bridge Desktop Help index](https://helpx.adobe.com/bridge/desktop.html), including its setup, workspace, organization, workflows, integrations, export, and troubleshooting sections. The ledger above accounts for each topic visible in that index as of the audit date. Troubleshooting links are grouped because they describe failure conditions rather than user capabilities; their individual applicability is release/OS dependent. This does not claim to exhaust undocumented behavior, third-party extensions, every format's support matrix, or Bridge's ExtendScript/SDK automation surface.
